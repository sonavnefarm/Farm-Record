# Livestock Farm Management System

A Next.js + PostgreSQL/Prisma application for tracking Buffaloes, Cows, and
Goats, and their Food, Milk, and Medicine records, with a Dashboard and
Analytics layer.

**Status:** Phase 0 (Planning) complete. No application code yet.

## Start Here

This project is built incrementally across multiple development sessions.
